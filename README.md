# 晚安动物园 SleepZoo 🐹🌙

> 在线体验：<https://thricenope.github.io/sleep-zoo/>（数据存在浏览器本地，换设备请用应用内导出/导入）

睡觉监测 × 节气 × Q版搞笑动物。**只记两件小事**：几点睡觉、几点起床——动物园的动物会比你还上心：睡得好它星星眼举手，熬夜它挂上咖啡吊瓶，凌晨三点还没睡它直接灵魂出窍，赖床超过 10 小时它戴上「赖床大王」皇冠。

> 独立第三个小应用，与 `slim-quest`（糖果消消乐版）、`slim-stars`（飞控星图版）互不相通。

## 玩法

- **今晚**：晚上按「去睡觉」→ 动物盖上小被子开始打呼 + **夜间进度条**走向 8 小时目标；早上按「起床啦」→ 彩带庆祝 + 透明评分卡。也可以随时「手动填时间 / 补历史」。
- **节气舞台**：界面跟随**二十四节气**（通式算法）——今天寒露就显示"睡前泡泡脚"，动物随季节换装（春花 / 夏草帽 / 秋围巾 / 冬毛线帽），每个节气配一句搞笑文案。
- **动物园**：连续达标夜数解锁 8 只Q版室友——旺财柴犬(2夜)、跳跳兔(3)、喵喵猫(5)、阿灵狐(7)、慢慢树懒(10)、夜夜猫头鹰(14)、冬冬熊(21)，点谁谁登场。
- **统计**：入住第 N 天、达标率、平均入睡/时长、连击纪录、近 14 夜时长柱状图（带 7–9h 黄金区浅带）、本月夜历、数据导出/导入。

## 评分规则（UI 内同步展示）

| 维度 | 分值 |
| --- | --- |
| 入睡时间 | ≤22:30 +3 · ≤23:30 +2 · ≤00:30 +1 · ≤3:00 -2 · 更晚 -4（修仙警告） |
| 睡眠时长 | 7–9h +3 · 6.5–7 或 9–10h +1 · 5.5–6.5h -2 · <5.5h -4 · >10h -2（冬眠警告） |

≥5 分 = 完美睡眠夜，≥2 = 达标夜，<0 = 熬夜警报夜。达标夜连击解锁动物。

## 快速开始

```bash
npm install
npm run dev      # 开发（5190 端口）
npm run build && npm run preview
```

数据在浏览器 localStorage（键 `sleep-zoo-v1`），无账号无后端。

## 技术栈

Vite + React 18 + TypeScript + zustand(persist) + framer-motion + canvas-confetti。字体：ZCOOL QingKe HuangYou + Baloo 2。8 只动物 × 8 种状态 × 4 季配饰全部手绘 SVG（无位图资源）。
